# Choose a workflow

Read the [51-skill catalog](../skills/README.md) for complete triggers, inputs, outputs, dependencies and cases. The [24 principles](../principles/README.md) support decisions inside workflows. A workflow summary does not replace reading its full skill and required contracts.

| Request | Start with | Expected artifact |
| --- | --- | --- |
| Understand runtime flow or historical reasons | [how](../skills/how.md), [why](../skills/why.md), [teach](../skills/teach.md) | Grounded explanation with source gaps |
| Compare competing shapes for one artifact | [Arena walkthrough](arena.md), [architect](../skills/architect.md) | Synthesized base, graft rationale and verification |
| Cover independent slices or race declared alternatives | [Swarm walkthrough](swarm.md) | Consolidated report with explicit gaps |
| Apply deliberate routing and proof discipline | [Poteto mode walkthrough](poteto-mode.md) | Selected playbook, checkpoint and inspected evidence |
| Review consequences or challenge a change | [blast-radius](../skills/blast-radius.md), [interrogate](../skills/interrogate.md) | Attributed risks and evidence |
| Resume, audit or record a run | [recall](../skills/recall.md), [show-me-your-work](../skills/show-me-your-work.md) | Scoped context or decision trail |
| Ask how to use pstack | [poteto-help](../skills/poteto-help.md) | One usable prompt and source |
| Review a source update | [upstream update walkthrough](../maintenance/upstream-updates.md) | Reviewed bundle, separate apply and acceptance gates |

Choose one [controller](../../references/workflow-ownership.md). Retain the active controller on unqualified requests. With none active, keep host defaults and do not silently activate a mode. A helper advises the owner without taking ownership. Resolve an explicit request for both controllers before dispatch or edits.

Check [compatibility](../compatibility.md) and [capabilities](../../references/host-capabilities.md) before execution. Workers need observed spawn and inspected results. Sequential role use is reduced capability. Exact requested models need supported exposed selections; actual models remain unknown until observed. Source-only help stays bounded by authorized reads.

Personalization begins only after all baseline dispositions are reviewed and both hosts have actual supported-behavior evidence or explicit blocks. [automate-me](../skills/automate-me.md), [reflect](../skills/reflect.md) and [setup-pstack](../skills/setup-pstack.md) retain their own review and persistence gates. No workflow grants setup, external writes, integration or scheduling permission.
