# Troubleshooting

Start with the exact frozen SHA, package version, host mode and failed operation. Record exposed tool name, observed result and limits. Use [capabilities](../references/host-capabilities.md) and [compatibility](compatibility.md). A static link or fixture result cannot repair missing host evidence.

| Symptom | Bounded check | Honest limit and next step |
| --- | --- | --- |
| Skill unavailable | Inspect actual package discovery and root enumeration against the [catalog](skills/README.md) | No loading permission or operation means blocked. Supplied source is a reduced explanation only. |
| Worker or execution unavailable | Inspect exposed spawn, wait, result and command bindings separately | Sequential alternatives are reduced capability; required independence or runtime proof remains blocked. |
| Stale installed cache | Compare actual installed identity/version/SHA to final frozen candidate | Source edits do not refresh installed bytes. Request exact refresh authorization and test in a fresh chat. |
| Model or effort rejected | Retain the actual rejection and current supported enumeration | Disclose authorized fallback; block when the exact choice is required. Requested names never prove actual models. |
| Broken reference | Read the exact target and run scoped [package validation](../tools/validate_package.py) through Bun | Stop dependent work. A summary cannot replace a required full read. |
| Missing integration | Inspect exposed connector/tool and permission without creating a connection | Keep dependent step blocked. No default MCP or app is bundled. |
| Helper setup-required | Check exact manifest, lock and local installed metadata with [helper setup](testing/helper-setup.md) | Bootstrap never installs. Historical snapshot success does not support this candidate. |
| Update conflict | Inspect old, candidate and adapted bytes plus caller list in [update review](maintenance/upstream-updates.md) | Resolve exact bytes and hashes; obtain exact approval before apply. Never apply draft.patch mechanically. |
| Stale verification | Compare record SHA/version and operation artifacts to tested candidate | Regather observations. No pass transfers across changed operative bytes or navigation. |
| Missing persistence or interrupted action | Inspect prior identity, destination and durable readback under [assignment contract](../references/orchestration-contract.md) | Unknown outcome blocks replay. Missing persistence prevents a cross-session recovery claim. |
| Failed candidate or recovery | Retain diff, apply report and immutable commits; inspect [rollback procedure](maintenance/rollback.md) | No destructive reset. Rollback needs exhaustive ownership, state review and exact preview approval. |

Run validator CLIs from the package root through Bun with `python3 -B` children and `--no-install`; exact examples are in the [maintenance guide](maintenance/upstream-updates.md). Structural success proves references and schema only. See separate [ChatGPT](setup/chatgpt.md) and [Codex](setup/codex.md) setup branches.
