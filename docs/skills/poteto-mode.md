Full capability expectation:

A fresh worker reads the full mode and applied leaves, follows the selected playbook with verbatim step todos or explicit skips, and returns blocking first steps, independent workstreams, shared mutable state and smallest safe decomposition with reasons for any n/a item. The coordinator inspects artifacts and reports evidence, decisions, limitations and only principles read in this session. The no-spawn delegate returns its own scoped diff for lead review. The coordinator reads selected helper contracts and inspects actual receipts, validates assignment and current full head against existing artifacts, and preserves each playbook delivery exception. All 23 routes and 24 principle bindings remain available as instructions.

Reduced capability expectation:

Without authorized independent workers, the same full reads and checkpoint apply to authorized sequential work. The result explicitly records reduced capability, unverified model diversity and absent independent review or background execution. Missing external companion skills are visible and their dependent gates remain blocked. Local checklist fallback retains verbatim steps and explicit skips. Inert helper fixtures support structural contracts only. An isolated snapshot run supports only its tested revision and never this caller or current host.

Blocked capability expectation:

If the mode, chosen playbook or applied principle leaf cannot be read, stop dependent work and name the missing reference. Denied execution or writes stay blocked; autonomy language grants no external permission, installation or controller takeover. Missing pinned dependencies stop dependency-backed helpers without install or bootstrap bypass. Stale identities, changed heads, missing artifacts, denied action permission or unknown interrupted outcome block affected integration or replay. Required independent review remains blocked even if a no-spawn worker can prepare a diff.
