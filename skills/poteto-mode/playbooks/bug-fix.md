### Bug fix

**You own this task. Plan, review, verify.** Delegate investigation and the fix to subagents, stay in the lead. Read the complete [mode](../SKILL.md), applied principle leaves and routed skills. Record these six steps before task-specific todos.

Use [session capabilities](../../../references/host-capabilities.md), [model roles](../../../references/model-roles.md) and the [assignment contract](../../../references/orchestration-contract.md). Supply the complete [poteto role prompt](../../../references/agent-prompts/poteto-agent.md) to ad-hoc investigators and code delegates; routed skills retain their own roles. Assign exact input revisions, scopes, ownership and success criteria. Inspect artifacts and review the diff yourself. Missing independent workers allow authorized sequential work only as reduced capability. Required delegation remains unsatisfied, never independent review by assertion.

Be scientific. Every shipped line traces to runtime evidence. Belt-and-suspenders that "might help" is a hypothesis, not a fix. It does not ship. When evidence refutes a hypothesis, revert what it motivated. The smallest change the evidence justifies ships, nothing more.

1. Reproduce it yourself on the matching surface via the control skill in the mode's Non-negotiables, even when a debug or instrumentation protocol says to ask the user to reproduce. Ask the user only with a stated, specific reason the control surface cannot reach the target, and only after driving it as far as it goes. If it won't reproduce directly, synthesize the trigger, tighten conditions, or instrument until it fires. Record the exact symptom, trigger, surface, revision, command or action, exit status where available, and output before changing production code. Missing control companions or denied execution leave the original reproduction unverified. A proxy check cannot satisfy the matching-surface gate.
2. Binary-search the cause. Form candidate hypotheses, then rule them out until one survives. Seed them with [how](../../how/SKILL.md) over the affected subsystem and [why](../../why/SKILL.md) for regression history, using their complete prompts and source contracts. Each pass takes the split that cuts the most remaining problem space, gets runtime evidence and eliminates candidates. When program state is unclear, add authorized instrumentation or logging and read it as the code runs. Don't guess. Drive a long or stubborn hunt with an exposed, authorized repeated-execution operation. If unavailable, perform bounded in-session iterations and disclose reduced capability, without claiming a background loop. Confirm the surviving mechanism with runtime evidence before the step-3 architect/interrogate fan-out.
3. Plan the fix. If it crosses a function boundary, [architect](../../architect/SKILL.md) first, using its complete exploration, runner, rationale and screening contracts. Contested design follows the mode's [interrogate](../../interrogate/SKILL.md) gate. Delegate implementation to a subagent using the configured bug-fix role with a specific scope. The portable default is inherited model and effort. The canonical default `grok-4.7-xhigh-fast` is historical provenance, not current availability. Select a configured model only when supported by exposed tools and observed; retain rejected selections and disclosed fallbacks. Unknown actual models prove no diversity. No required independent operation means that gate remains blocked.
4. Verify on the same surface. The original repro now passes. Retain the same trigger and conditions and record the actual output after the bounded root-cause fix. "Inconclusive" or wrong-surface is not a pass. Flag it. Unit tests show branch behavior, not bug absence. Keep denied controls, missing companions and unrun checks explicit.
5. Stage the commits so the failing repro lands before the fix in git history. See [tdd](../../tdd/SKILL.md) for the failing-test-first cadence when the bug has a cheap local test path. Skip adding that test when it would be expensive, integration-heavy or unclear, and state the reason and closest executable regression check. This is the canonical [sequence-verifiable-units](../../principle-sequence-verifiable-units/SKILL.md) principle skill, the failing test first and the fix on top. Commits, rebases and history changes require actual authorization and available operations. Without them, preserve the failing-before/passing-after artifacts and ordered delivery plan; do not claim that sequence landed.
6. Run [Opening a PR](opening-a-pr.md) in full when its dependency and required capabilities are available and authorized. Missing playbook or companion gates stop dependent delivery. Return checked local artifacts and the exact unperformed actions otherwise. PR creation and other external writes require explicit authorization. Opening a PR does not implicitly start Babysit.

**Reply:** what was broken, root cause, fix, how you verified. Paste failing-then-passing repro output verbatim. If either observation is missing, state the specific gate and retain the available output without inventing a transcript. Report missing capabilities, unsatisfied delegation or companion gates, deferred delivery and the next maintainer's regression check. Apply the local [unslop](../../unslop/SKILL.md) contract.
