# pstack-openai

A documentation-only design repository for a full pstack port to personal ChatGPT and Codex.

Read the [design spec](docs/superpowers/specs/2026-10-07-pstack-openai-design.md). It accounts for all 51 root skills, 24 principles, and 164 files in the pinned upstream baseline, including orchestration and optional integrations.

The canonical source is [Lauren Tan's pstack v0.15.15](https://github.com/cursor/plugins/tree/df581122cde17e6e27686b5a448bde23e4ad4318/pstack). This unofficial port retains the MIT attribution in the spec. FetchUpstream's smaller ChatGPT port is a comparison reference.

Status: written design awaiting user review. No plugin, runtime, dependencies, or installation exists here. Spec approval comes before an implementation plan, and plan review comes before any build or installation.
